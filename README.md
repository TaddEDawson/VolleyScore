# VolleyScore

Open [index.html](index.html) directly in a browser to keep score offline. No
installation, server, or internet connection is required. The clock shows your
device's local time, and scores use a seven-segment display.

- Tap the top half of a side to add a point.
- Tap the lower half of that side to subtract a point. Scores never go below `00`.
- The countdown at the top starts automatically at `:58` each hour. Tap `2:00`
  to start it early. An early countdown already running at `:58` keeps going.
- The first side to reach 25 with a lead of at least two points wins the set.
  After a win, you can still subtract points to correct the score. If the
  correction removes the win, scoring and the set timer resume. The set timer
  below the local clock starts with the first point and stops at a win.
- Select **New set** to reset both scores and the set timer.
