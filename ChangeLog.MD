# Changelog

## 1.0.2 - 2026-11-24

- Added a red and blue rally strip and volleyball buttons for selecting the first server.
- Added a running-score step chart to the completed-set recap, including corrections.

## 1.0.1 - 2026-11-24

- Added the # statistics button and an offline set timeline showing event time,
  team, rotation, and score for points, corrections, timeouts, and set transitions.
- Added first-server selection. Both teams start in rotation 1 and rotate on
  gaining serve. Score corrections recalculate rotations from remaining points.
- Timeout entries preserve the score when called, with the calling team first.
- Statistics are cleared on a confirmed new set or page reload.

## 1.0.0

- Introduced offline red and blue seven-segment scoring, win-by-two rules,
  score corrections, winner indicators, and completed-set summaries.
- Added manual and hourly two-minute countdowns, set duration, and two
  30-second team timeouts with saved score snapshots.
- Added full screen, help, reset confirmation, transparent overlays, and
  enlarged icons and timer text.
