VolleyScore Help

Version 1.0.1

  • Score: Tap the upper half of the red or blue side to add a point. Tap the lower half to subtract one. Scores cannot go below 00.
  • Win: Reach at least 25 points with a two-point lead. After a win, additions stop, but corrections can reopen the set.
  • Set timer: Tap the set timer to start it, or award the first point. It stops at a win, and resumes if a correction removes the win.
  • Timeouts: Each team has two 30-second timeouts per set. Only one timeout can run at a time; the set timer keeps running. Select a stopwatch icon to start. Completed timeouts show the score when called, with the calling team's score first, and stay greyed out until a new set.
  • Countdown: Tap 2:00 to start a two-minute countdown before minute :58. It also starts automatically at :58 each hour, counting down to the next hour. A countdown already running keeps its end time. It is dimmed while idle and brightens when started. Active countdowns cannot restart; expiration shows TIMES UP without sound.
  • New set (circular arrows): Asks for confirmation before clearing scores or timers already in use. Cancel keeps the current set. After a win, the confirmation shows the final score and set timing details. During minutes :58 and :59, it cancels that hour's automatic countdown.
  • Full screen (diagonal arrows): Expand the scoreboard to fill the screen. Select the icon again or press Escape to leave full-screen mode.
  • Statistics (#): View the current set timeline. Choose the first server before scoring. Both teams start in rotation 1; the team gaining serve rotates to the next position, wrapping from 6 to 1. Corrections undo that team's latest uncorrected point and recalculate rotations. New set clears the timeline.
  • Offline: No internet is needed. The date and time use the local device clock. Reloading or closing the page loses scores and timers.

Help does not pause timers. Use Tab to focus controls and Enter or Space to activate them. Close this popup with Close or Escape.
